## How to Use This Repo

1. **Each week**: pick problems (see `problems/`), fill one `PROBLEM_TEMPLATE.md` per problem.
2. **Model first**: follow the workflow in `docs/METHODOLOGY.md` before coding.
3. **Log progress**: copy `WEEKLY_LOG_TEMPLATE.md` into `weekly-logs/` and fill it in.
4. **Refine the workflow**: update `METHODOLOGY.md` whenever a step proves weak.
5. **At month ends**: review logs, update status and milestones below.
