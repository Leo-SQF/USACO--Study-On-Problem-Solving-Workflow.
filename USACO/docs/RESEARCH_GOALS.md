# Research Goals

<!-- Clear, measurable goals for the 4-month project. Review and update every
month. -->

## Main Goal

> To design, test, and refine a **standardized modeling workflow** that turns
> USACO problem statements into correct solutions consistently and fast.

## Sub-Goals

### G1 — Understand the workflow (Month 1)
- [ ] Identify the 5–6 key steps of a modeling workflow (read, model, design, code, verify).
- [ ] Write workflow **v0.1**.
- [ ] Apply it to `N` warm-up problems.

### G2 — Build the algorithm toolbox (Month 2)
- [ ] Map common USACO patterns (sorting, graphs, DP, greedy, etc.) to algorithm choices.
- [ ] Write a **decision checklist** for choosing algorithms.
- [ ] Update workflow to **v0.2**.

### G3 — Apply under contest conditions (Month 3)
- [ ] Solve full problems with a time limit.
- [ ] Run at least `3` timed mock sessions.
- [ ] Record time-to-first-correct for each.

### G4 — Contest + write-up (Month 4)
- [ ] Participate in a real USACO round (if timing allows).
- [ ] Produce the **final workflow** document.
- [ ] Write a short reflection on what changed over 4 months.

## Metrics to Track

| Metric | How to measure | Start value | Target value |
|--------|----------------|-------------|--------------|
| Solve rate | correct / attempted | `X%` | `Y%` |
| Avg time to solve | minutes per problem | `X min` | `Y min` |
| Template completion | templates filled / problems attempted | `X%` | `Y%` |
| Self-rated confidence | 1–10 after each problem | `X` | `Y` |

## Non-Goals

- Winning a specific medal (nice-to-have, not a hard goal).
- Building a full library of every algorithm ever used.
